# Cloud Billing documentation 



[Read product documentation](https://berlin.devsitetest.how/billing/docs/concepts)

















Cloud Billing is a
[collection of tools](/billing/docs/concepts)
that help you track and understand your
Google Cloud Dedicated spending, pay your bill, and optimize your costs.

A [Cloud Billing account](/billing/docs/how-to/manage-billing-account)
defines who pays for a given set of Google Cloud Dedicated in Germany resources. To use Google Cloud Dedicated in Germany
services, you must have a valid Cloud Billing account, and must link it to your
Google Cloud Dedicated projects. Your project's Google Cloud Dedicated usage is charged to the linked
Cloud Billing account.
