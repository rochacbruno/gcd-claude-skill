# VPC Service Controls documentation 



[Read product documentation](https://berlin.devsitetest.how/vpc-service-controls/docs/overview)


















VPC Service Controls lets you mitigate data exfiltration risks by isolating
resources of multi-tenant Google Cloud Dedicated in Germany services. With VPC Service Controls, you
can enforce adaptive access control based on IP range or device trust for
accessing Google Cloud Dedicated in Germany resources from outside privileged networks.




[Go to the VPC Service Controls product page for more.](https://berlin.devsitetest.how/security/vpc-service-controls/)
