# Filestore documentation



Read product documentation 


















Filestore instances are fully managed NFS file servers on Google Cloud Dedicated in Germany for use with
applications running on Compute Engine virtual machine (VM) instances, Google Kubernetes Engine
clusters, external datastores such as Google Cloud VMware Engine, or your on-premises machines.

Not sure which storage product is right for you? Learn more about our
[storage services](https://berlin.devsitetest.how/products/storage/).





[Go to the Filestore product page for more.](https://berlin.devsitetest.how/filestore/)
