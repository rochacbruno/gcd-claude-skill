# Agent Platform overview 















Gemini Enterprise Agent Platform is a platform that supports the machine learning lifecycle by providing
tools to discover, manage, and deploy open models from Model Garden.

## Gemini Enterprise Agent Platform Components

The platform provides tools to support the machine learning lifecycle:

- [**Model Garden:**](/gemini-enterprise-agent-platform/models/model-garden/explore-models)
Access a variety of open and open-source models.

- [**Model Registry on Gemini Enterprise Agent Platform:**](/gemini-enterprise-agent-platform/machine-learning/model-registry/introduction)
A repository to manage model versions and lifecycle.

- **Online Inference:** Deploy models to endpoints to serve online predictions with low latency.
