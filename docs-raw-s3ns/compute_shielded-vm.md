# Shielded VM documentation 



[Read product documentation](https://documentation.s3ns.fr/compute/shielded-vm/docs/shielded-vm)


















Shielded VM provides verifiable integrity of your Compute Engine VM
instances, so you can be confident that your instances haven't been compromised by
boot- or kernel-level malware or rootkits.




[Go to the Shielded VM product page for more.](https://documentation.s3ns.fr/security/products/shielded-vm)
