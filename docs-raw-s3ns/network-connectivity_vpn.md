# Cloud VPN documentation 



[Read product documentation](https://documentation.s3ns.fr/network-connectivity/docs/vpn/concepts/overview)


















Cloud VPN securely extends your peer network to Google's network
through an IPsec VPN tunnel. Traffic is encrypted and travels between the two
networks over the public internet. Cloud VPN is useful for
low-volume data connections. For additional connection options, see the
[Hybrid Connectivity](https://documentation.s3ns.fr/hybrid-connectivity/) product page.
