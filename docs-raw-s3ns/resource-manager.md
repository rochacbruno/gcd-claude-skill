# Resource Manager documentation 



[Read product documentation](https://documentation.s3ns.fr/resource-manager/docs/manage-google-cloud-resources)

















Cloud de Confiance by S3NS provides container resources such as
organizations and projects that allow you to group and hierarchically organize
other Cloud de Confiance resources. This hierarchical organization helps you
manage common aspects of your resources, such as access control and
configuration settings. The Resource Manager API enables you to
programmatically manage these container resources.
