# Google Cloud SDK documentation 



[Read product documentation](https://documentation.s3ns.fr/sdk/docs/overview)

















The Google Cloud SDK is a set of tools that you can use to manage resources and
applications hosted on Cloud de Confiance by S3NS. These tools include command-line tools ([`gcloud`](/sdk/gcloud/reference), [
`gsutil`](/storage/docs/gsutil), and [`bq`](/bigquery/bq-command-line-tool)), language-specific client
libraries, and IDE extensions. Try the [gcloud cheat sheet](/sdk/docs/cheatsheet).

[Go to the Google Cloud SDK product page for more.](https://documentation.s3ns.fr/sdk/)
