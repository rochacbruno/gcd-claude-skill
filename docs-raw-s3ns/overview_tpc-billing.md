Your partner, S3NS, handles pricing and billing in
Cloud de Confiance. If you have any questions about pricing or billing, contact
[Cloud de Confiance by S3NS billing support](https://support.s3ns.fr/).

## What is Cloud Billing? 

Cloud Billing is a collection of tools that help you track and
understand your Cloud de Confiance by S3NS spending, pay your
bill, and optimize your costs. Because
Cloud de Confiance is a local, isolated cloud
based on Google Cloud, [not all Cloud Billing features
that are available in Google Cloud can be used in
Cloud de Confiance](/billing/docs/tpc-differences).

A Cloud Billing account defines who pays for a given set of
Cloud de Confiance resources. To use
Cloud de Confiance services, you must have a valid
Cloud Billing account, and must link it to your
Cloud de Confiance project(s). Multiple projects
can have their resource usage billed to the same account.

You can learn more about Cloud Billing in its [documentation](/billing/docs/concepts).
