# Quotas and limits 














Calls to API Keys are subject to the following quotas:



| 
API call type | 
Limit | 
|



| 
Read-only calls | 
240 API calls per minute. | 
|

| 
Write calls | 
120 API calls per minute. | 
|



To request an increase to these quotas:

- In the Cloud de Confiance console, go to the **IAM & admin** > **Quotas** page.

[Go to Quotas](https://console.cloud.s3nscloud.fr/iam-admin/quotas)

- Select the **API Keys API** quota that you want to increase: **Read requests
per minute** and/or **Write requests per minute**.

- Click add **Edit Quotas**.

- Fill out the form on the right side.

- Click **Submit request**.
