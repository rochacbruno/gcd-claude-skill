# Service Directory documentation 



[Read product documentation](https://documentation.s3ns.fr/service-directory/docs/overview)

















Service Directory is a platform for discovering, publishing, and
connecting services, regardless of the environment. It provides real-time
information about all your services in a single place, allowing you to perform
service inventory management at scale, whether you have a few service endpoints
or thousands.
