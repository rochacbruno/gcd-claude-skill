# Filestore release notes 


















This page documents production updates to Filestore. You can
periodically check this page for announcements about new or updated features,
bug fixes, known issues, and deprecated functionality.







You can see the latest product updates for all of Cloud de Confiance by S3NS on the
[
Cloud de Confiance](/release-notes) page, browse and filter all release notes in the
[Cloud de Confiance console](https://console.cloud.s3nscloud.fr/release-notes),
or programmatically access release notes in
[BigQuery](https://console.cloud.s3nscloud.fr/bigquery?p=bigquery-public-data&d=google_cloud_release_notes&t=release_notes&page=table).













To get the latest product updates delivered to you, add the URL of this page to your
[feed
reader](https://wikipedia.org/wiki/Comparison_of_feed_aggregators), or add the
[feed URL](https://documentation.s3ns.fr/feeds/filestore-release-notes.xml) directly.









## October 20, 2026


Feature 


Filestore is available in Cloud de Confiance. For more information, see [Filestore differences in Google Cloud versus Cloud de Confiance](/filestore/docs/tpc-differences).



## November 18, 2024


Feature 


Filestore is now available in Mexico ([`northamerica-south1`](/filestore/docs/regions) region).



## October 07, 2024


Feature 


[Deletion protection](/filestore/docs/deletion-protection) is now [generally available](https://documentation.s3ns.fr/products#product-launch-stages) for Filestore instances.



## September 30, 2024


Feature 


[NFSv4.1 protocol](/filestore/docs/about-supported-protocols) support, integrated with Managed Service for Microsoft Active Directory, is now generally available for zonal, regional, and enterprise instances.



## June 04, 2024


Change 


Filestore instances no longer require reserved capacity for certain internal operations. For more information, see [Monitoring instances](/filestore/docs/monitoring-instances#anticipating-capacity).
