This page contains release notes for features and updates to Cloud DNS.







You can see the latest product updates for all of Cloud de Confiance by S3NS on the
[
Cloud de Confiance](/release-notes) page, browse and filter all release notes in the
[Cloud de Confiance console](https://console.cloud.s3nscloud.fr/release-notes),
or programmatically access release notes in
[BigQuery](https://console.cloud.s3nscloud.fr/bigquery?p=bigquery-public-data&d=google_cloud_release_notes&t=release_notes&page=table).













To get the latest product updates delivered to you, add the URL of this page to your
[feed
reader](https://wikipedia.org/wiki/Comparison_of_feed_aggregators), or add the
[feed URL](https://documentation.s3ns.fr/feeds/dns-release-notes.xml) directly.









## January 30, 2025 


Feature 


[DNS64](/dns/docs/overview#dns64-overview) is now available in **[Preview](https://documentation.s3ns.fr/products/#product-launch-stages)**.



## August 08, 2024


Feature 


You can now select internal proxy Network Load Balancers as a health checked target for DNS routing policies in **[Preview](https://documentation.s3ns.fr/products/#product-launch-stages)**. For more information, see [DNS routing policies and health checks](/dns/docs/routing-policies-overview).



## July 31, 2024


Feature 


[Health checks for external endpoints](/dns/docs/routing-policies-overview#health-checks-internet) in Cloud DNS routing policies are now available in **[Preview](https://documentation.s3ns.fr/products/#product-launch-stages)**.
