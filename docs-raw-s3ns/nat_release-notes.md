# Cloud NAT release notes 


















This page contains release notes for features and updates to Cloud NAT.







You can see the latest product updates for all of Cloud de Confiance by S3NS on the
[
Cloud de Confiance](/release-notes) page, browse and filter all release notes in the
[Cloud de Confiance console](https://console.cloud.s3nscloud.fr/release-notes),
or programmatically access release notes in
[BigQuery](https://console.cloud.s3nscloud.fr/bigquery?p=bigquery-public-data&d=google_cloud_release_notes&t=release_notes&page=table).













To get the latest product updates delivered to you, add the URL of this page to your
[feed
reader](https://wikipedia.org/wiki/Comparison_of_feed_aggregators), or add the
[feed URL](https://documentation.s3ns.fr/feeds/cloudnat-release-notes.xml) directly.









## April 13, 2026


Feature 


**General Availability**: Cloud NAT gateways for Public NAT support
[source-based NAT rules](/nat/docs/nat-rules-overview) for IPv4 addresses.



## September 23, 2025


Feature 


**Preview**: Cloud NAT gateways for Public NAT support [source-based NAT rules](/nat/docs/nat-rules-overview) for IPv4 addresses.
