# Cloud Billing documentation 



[Read product documentation](https://documentation.s3ns.fr/billing/docs/concepts)

















Cloud Billing is a
[collection of tools](/billing/docs/concepts)
that help you track and understand your
Cloud de Confiance spending, pay your bill, and optimize your costs.

A [Cloud Billing account](/billing/docs/how-to/manage-billing-account)
defines who pays for a given set of Cloud de Confiance by S3NS resources. To use Cloud de Confiance by S3NS
services, you must have a valid Cloud Billing account, and must link it to your
Cloud de Confiance projects. Your project's Cloud de Confiance usage is charged to the linked
Cloud Billing account.
