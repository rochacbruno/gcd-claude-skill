# Managed Service for Apache Airflow documentation



Read product documentation 

















Managed Service for Apache Airflow, previously known as Cloud Composer, is a managed
[Apache Airflow](https://airflow.apache.org) service
that helps you create, schedule, monitor and manage workflows. Managed Airflow automation
helps you create Airflow environments quickly and use Airflow-native tools, such as the powerful
Airflow web interface and command line tools, so you can focus on your workflows and not your
infrastructure.

[Go to the Managed Service for Apache Airflow product page for more.](https://documentation.s3ns.fr/composer/)
